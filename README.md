# Итоговая работа: Python для анализа данных

Основной файл — **analysis.ipynb**. В нём выполнены все шесть заданий,
сохранены результаты запуска, таблицы, графики и выводы.

Для просмотра без Python откройте **analysis.html** в браузере.

## Состав

- `analysis.ipynb` — ноутбук с решением.
- `analysis.html` — версия для просмотра.
- `data/` — исходные `orders.xlsx` и `products.xlsx` без изменений.
- `results/` — шесть таблиц CSV и четыре графика PNG.
- `requirements.txt` — библиотеки для повторного запуска.

## Повторный запуск

1. Распаковать весь архив, сохранив папки `data` и `results` рядом с ноутбуком.
2. Из папки проекта установить библиотеки:

   `python -m pip install -r requirements.txt`

3. Запустить `python -m jupyterlab` и открыть `analysis.ipynb`.
4. Выполнить все ячейки по порядку (`Run All Cells`).

Используются Python 3.10+, pandas, numpy, matplotlib и openpyxl для чтения Excel.
Код представляет собой последовательные расчёты в pandas. Отдельная функция
используется для двух одинаковых по логике ABC-анализов.

## Особенности расчётов

- Количество — сумма `quantity`, выручка — сумма `quantity * price`.
- Средний чек считается по всем строкам продаж, включая товары без справочника.
- В остальных заданиях товары без справочника исключены, как разрешено условием.
- Маржа в процентах — отношение маржи к выручке, не к себестоимости.
- Для категорий без продаж процентная маржа не определена.
- ABC выполнен по подкатегориям с продажами; правило границ 80%/95% описано в ноутбуке.
- В данных только 13 января 2022 года. Выводы ограничены этой выборкой.
