Итоговый проект: Python для анализа данных¶

Анализ продаж по таблицам orders.xlsx и products.xlsx.

Задание: https://app.simulative.ru/course/14/1090
Данные: https://disk.yandex.ru/d/EkSfw6q9qLKmNA

Нужно сравнить продажи по категориям, рассчитать средний чек, долю промо, маржу и сделать ABC-анализ по подкатегориям. Под количеством продаж понимаю сумму quantity, а под суммой продаж — quantity * price.

Подготовка и проверка данных¶

Сначала проверяю типы, пропуски и повторы. Товары соединяю с продажами по product_id. У каждого ID в справочнике должна быть одна строка, иначе соединение может искусственно увеличить продажи.

5. Маржа по категориям¶

Маржа в рублях = выручка − закупочная стоимость = sum(quantity * (price - cost_price)).

Маржа в процентах = маржа в рублях / выручка × 100%. В знаменателе использую выручку, а не себестоимость: иначе получилась бы наценка. Это валовая маржа без учёта доставки, зарплат и других операционных расходов.

6. ABC-анализ по подкатегориям¶

Отдельно ранжирую подкатегории по количеству и по фактической выручке. Единица анализа — пара «категория, подкатегория».

Правило: сортирую показатель по убыванию и считаю накопленную долю. До 80% включительно — A, от 80% до 95% включительно — B, свыше 95% — C. Подкатегория, пересекающая границу, относится к следующей группе, поэтому доля группы A может быть немного меньше 80%. При равных значениях порядок задаётся названиями категории и подкатегории.

Анализирую подкатегории с продажами. По одному дню не стоит принимать окончательное решение об исключении подкатегорий из ассортимента.

subcategory_sales = sales.groupby(['level1', 'level2'], as_index=False).agg(
    quantity=('quantity', 'sum'), revenue=('revenue', 'sum'))

def abc_analysis(table, metric):
    result = table[['level1', 'level2', metric]].copy()
    result = result.sort_values([metric, 'level1', 'level2'], ascending=[False, True, True])
    result['share'] = result[metric] / result[metric].sum()
    result['cumulative_share'] = result['share'].cumsum()
    result['group'] = np.select(
        [result['cumulative_share'] <= 0.80, result['cumulative_share'] <= 0.95],
        ['A', 'B'], default='C')
    return result
